drinkR: Estimate your Blood Alcohol Concentration (BAC)
======

This app is live at <https://rasmusab.github.io/drinkr/>  and you can find [more info regarding drinkR at my blog](http://www.sumsar.net/blog/2014/07/estimate-your-bac-using-drinkr/).

This repository contains both a regular Shiny version (`../shiny_app`) and a version adapted for Shinylive that runs completely in the browser (`../shinylive_app`).
